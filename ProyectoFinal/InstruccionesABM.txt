Comando para powershell para montar la DB en docker:
docker run --name mysql-jyaa-test `
  -e MYSQL_ROOT_PASSWORD=root `
  -e MYSQL_DATABASE=jyaa `
  -e MYSQL_USER=jyaa `
  -e MYSQL_PASSWORD=jyaa `
  -p 3306:3306 `
  -d mysql:8.0

**ROL**
Servlet: RolServlet.java
Ruta: /rol
Uso: Funcionalidades para CRUD de los roles (igualmente seria raro cambiar el tipo de un rol ya creado o eliminarlo)
	 	pero igualmente se provee la funcionalidad.
[TipoRol = ADMINISTRADOR, ORGANIZACION_SOCIAL, PERSONAL_SALUD]
Métodos:

get(): Listar todos los roles
get(id): Listar un rol por id
get(tipo<TipoRol>): Listar un rol por nombre 

post(tipo<TipoRol>): Crear un rol (perteneciente al enum definido en rol.java, no se puede definir un rol nuevo)

put(id, tipo<TipoRol>): Modificar un rol (permite cambiar el tipo de rol a un id de rol dado. No admite el nuevo tipo si
						el rol ya existe)

delete(id): Eliminar un rol y las asociaciones a los usuarios que lo tengan asignado.

**USUARIO**
Servlets: UsuarioServlet.java, RolUsuarioServlet.java
Ruta: /usuario
Uso: Funcionalidades para CRUD, activacion, y asociacion a barrio (Org social) de los usuarios
action: "update" para modificar x campos de un usuario, "activate" para activar un usuario
Metodos:
get(): Listar todos los usuarios
get(id): Listar un usuario por id
post(mail, password, name, address, extra, activity): Crear un usuario (no se puede crear un usuario con el mismo mail)
	 address, extra, activity son opcionales.
put(action, id, is_active): con "action" = activate, alterna la activacion del usuario (true o false en el parametro is_active)
put(action, id, mail, password, name, address, extra, activity): con "action" = update, cambia cualquiera de los campos (todos opcionales excepto action y id)
put(action, id, barrioId): con "action" = barrio, asocia un barrio a un usuario (org_social)
delete(id): elimina el usuario con el id indicado (tambien elimina sus entradas en la tabla usuario_rol)

Ruta: /rolusuario
Uso: Funcionalidades para añadir o quitar un rol a un usuario.
action: "addRoleToUser" (añade el rol), "removeRoleFromUser" (quita el rol)
Métodos:
post(action, rolId, userId): Asignar o quitar un rol a un usuario dependiendo del "action" que se pase.

**CAMPAÑA**
Servlet: CampañiaServlet.java
Ruta: /campania
Uso: Funcionalidades para CRUD de las campañas
Metodos:
Formato de las fechas: yyyy-MM-dd
get(): Listar todas las campañas
get(id): Listar una campaña por id
get(nombre): Listar una campaña por nombre
post(name, startDate, endDate): Crear una campaña (no se puede crear una campaña con el mismo nombre)
put(id, name, startDate, endDate): Modificar una campaña (no se puede modificar el nombre a uno ya existente)
delete(id): Eliminar una campaña

**BARRIO**
Servlet: BarrioServlet.java
Ruta: /barrios
Uso: Funcionalidades para CRUD de los barrios
Metodos:
get(): Listar todos los barrios
get(id): Listar un barrio por id
post(): En el body recibe un BarrioDTO, y crea el barrio junto a las coordenadas que se les asigna (almenos 3)
put (id): En el body recibe un BarrioDTO, y actualiza el barrio obtenido por parametro con los valores del body
	-> Si recibe 3 coordenadas o +, elimina las persistidas y crea las nuevas coordenadas
	-> Si no, deja las persistidas
delete (id): Elimina un barrio

**Zona**
Servlet: ZonaServlet.java
Ruta: /zonas
Uso: Funcionalidades para CRUD de las zonas
Metodos:
get(): Listar todas las zonas
get(id): Listar una zona por id
get(barrioId): Listar las zonas de un barrio
post(): En el body recibe una ZonaDTO, y crea la zona junto a las coordenadas que se les asigna
put (id): En el body recibe una ZonaDto, y actualiza el id de la zona obtenida por parametro con los valores del body
	-> Si recibe 3 coordenadas o +, elimina las persistidas y crea las nuevas coordenadas
	-> Si no, deja las persistidas
	-> Si recibe un barrioId, asigna la zona a ese barrioId
delete (id): Elimina una zona

**Encuestas**
Servlet: EncuestaServlet.java
Ruta: /encuesta
Uso: Funcionalidades para CRUD de las encuestas
Metodos:
get(): Listar todas las encuestas
get(id): Listar una encuesta por id
get(tipo): Listar las encuestas por tipo indicado
get(viviendaId): Listar las encuestas asignadas a una encuesta de vivienda id
get(campañaId): Listar las encuestas tipo vivienda asignadas a una campaña
post(tipo, viviendaId?, campañaId?): Crea una encuesta con el tipo indicado. En caso de ser PERSONA, se debe asignar una encuesta del tipo
	vivienda relacionada, y en caso de ser una encuesta de tipo VIVIENDA, se le debe asignar una campaña
put (encuestaId, renglonId): Asigna un renglon a una encuesta
delete (id): Elimina una encuesta. Si es vivienda, no puede tener personas asignadas.
